# Water Quality Risk Assessment for Water-Borne Disease Prevention Using Machine Learning

 #Project Overview
This project uses machine learning techniques to assess water quality and help identify potential risks associated with unsafe drinking water. It explores water-quality data to support risk assessment and water-borne disease prevention.

## Objectives
- Analyze water-quality parameters.
- Apply machine learning to water-quality data.
- Evaluate model performance using appropriate classification metrics.
- Support early identification of potential water-quality risks.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

## Machine Learning
The project explores machine learning methods for water-quality classification and risk assessment. The models and evaluation results are documented in the project notebook.

## Project Files
- `water_quality_project.ipynb` — Google Colab notebook containing the project code and analysis.

## How to Run
1. Open the notebook in Google Colab.
2. Upload the required dataset.
3. Run the notebook cells in order.

## Dataset
The project uses water-quality data for analysis and model development. Refer to the notebook for the dataset details and preprocessing steps.

## Disclaimer
This project is intended for educational and research purposes. Its predictions should not replace laboratory water-quality testing or public-health guidance.
